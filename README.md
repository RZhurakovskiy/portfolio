# Портфолио — Роман Жураковский

Личный сайт-портфолио: веб и мобильная разработка.
Статика, без сборщиков и зависимостей — чистые HTML, CSS и JavaScript.

## Структура

```
index.html        — главная страница
livebeat.html     — кейс LIVEBEAT
nexora.html       — кейс Nexora
css/              — стили
js/               — скрипты
images/           — изображения и скриншоты кейсов
```

## Локальный запуск

Достаточно открыть `index.html` в браузере. Либо поднять простой сервер:

```bash
python -m http.server 8000
```

и перейти на http://localhost:8000

## Публикация

Сайт статический, поэтому разворачивается через GitHub Pages:
Settings → Pages → Source: `main` / `root`.
